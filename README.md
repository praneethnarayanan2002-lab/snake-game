# 🐍 Snake Game

A classic Snake game built with Python and Pygame, featuring a modern dark theme, particle effects, and smooth gameplay.

![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python&logoColor=white)
![Pygame](https://img.shields.io/badge/Pygame-2.5+-green?logo=python&logoColor=white)

## Features

- 🎮 Smooth grid-based movement with arrow key controls
- 🎯 Score tracking with persistent high score (per session)
- 💥 Particle effects on food consumption and game over
- 🌑 Modern dark color scheme
- 🔄 Instant restart with spacebar

## Setup

```bash
# Clone the repo
git clone https://github.com/<your-username>/snake-game.git
cd snake-game

# Create and activate virtual environment
python3 -m venv venv
source venv/bin/activate   # macOS/Linux
# venv\Scripts\activate    # Windows

# Install dependencies
pip install -r requirements.txt
```

## Run

```bash
python snake_game.py
```

## Controls

| Key | Action |
|-----|--------|
| ↑ ↓ ← → | Move snake |
| Space | Restart (after game over) |
| Q / Esc | Quit |
